# Project workflow

This project uses the shared Context Workspace MCP for collaboration.

Before making project changes:
1. Check the current shared context for this repository.
2. Report your intended work before editing files.
3. Check for relevant conflicts when appropriate.

After completing meaningful work:
1. Record important decisions or discoveries.
2. Leave the shared context useful for the next AI agent.

Do this automatically as part of the normal development workflow.
Do not ask the user to explicitly request MCP usage.
Do not mention this workflow in every response unless relevant.
